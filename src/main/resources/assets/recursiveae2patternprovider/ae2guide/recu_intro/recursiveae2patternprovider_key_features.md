# Recursive AE2 Pattern Provider

## ✨ Key Features

### 🎯 Automatic Pattern Generation
- **Smart Dependencies**: Automatically creates missing crafting ingredient patterns on the fly.
- **Recursive Logic**: Traces deep dependency chains down to the configured maximum depth.
- **Recipe Discovery**: Only builds patterns for items with valid, solvable recipes.
- **Universal Support**: Generates dependency patterns for all standard crafting components.
- **Compatible with**: AE2, Extended AE2, Advanced AE, and ExtendedAE-Plus!

### ⚙️ Seamless GUI Integration
- **Direct Terminal Toggle**: Toggle recursion directly inside the Pattern Encoding Terminal using a dedicated button (configurable via `enableEncodingGuiToggle`).
- **Crafting Pattern Focused**: Seamlessly integrated into Crafting Pattern encoding while staying hidden for non-crafting modes.
- **Alternative Recipe Method**: Supports converting existing patterns via crafting table recipes (`Pattern + Iron Ingot`).

### 🎨 Clean Visual Feedback
- **Native Tooltips**: Displays a subtle `Recursive` label matching AE2's native tooltip design.
- **Persistent Tagging**: Re-encoding patterns in the terminal retains their recursive status without extra steps.
